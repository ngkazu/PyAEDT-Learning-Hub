# 難易度基準

## 対象読者の前提

すべての難易度に共通する前提として、対象読者は
**「Python の基本文法は習得済みで、公式ドキュメント等を参照しながらコードを書ける人」**とする。

**難易度は Python の難しさではなく、AEDT/PyAEDT ドメインの複雑さで決める。**
具体的には、使う境界条件・解析タイプの数、パラメトリック設計の有無、マルチフィジックス連成の有無、
高レベルAPI・設定ファイルの活用度などが判断軸になる。

以下の時間・内容基準は目安であり、多少の逸脱を許容する（厳密なルールではない）。

## easy（目安30分）

- AEDT の基本操作全般を学ぶレベル。「起動 → 何かする → 保存 → 終了」という一連の流れを体験することが目的。
- 変数化、形状の作成・変更、物性の作成・変更などは代表的な例であり、これらに限定しない。
- アプリケーション固有の知識は問わない。モデリングパラダイムが近いアプリ同士で共通化し、
  `exercise/0.easy/common_3d/`（HFSS, Maxwell 3D, Icepak, Q3D Extractor, IcepakFEA）、
  `exercise/0.easy/common_2d/`（Maxwell 2D, 2D Extractor）、
  `exercise/0.easy/common_circuit/`（Circuit, EMIT, Twin Builder）の3グループに分ける。
- HFSS 3D Layout・EDB はレイヤー/ECAD操作でこの3区分になじまないため、easy の対象外（normal から開始）。
- **含む**: 変数定義、単純な形状/回路要素の作成・変更、物性の割り当て、保存・終了。
- **含まない**: Setup作成、解析実行、複雑な境界条件の使い分け、複数アプリの連成。

## normal（目安60分）

- ここからアプリケーション別の課題を中心にする。
- 「モデル作成 → Setup作成 → 解析実行」という自動化の基本を学ぶ。
- 外部モジュールの利用も視野に入れる（例: CSVインポートから境界条件を割り当てる）。
- ポスト処理は AEDT 内で完結する簡単なものに留める（レポート作成程度）。
- **含む**: 単一アプリでのモデル作成・Setup作成・解析実行・基本的なレポート作成。
- **含まない**: 複数アプリにまたがる連成解析、高度なポスト処理、Pythonでのカスタムデータ処理。

## hard（目安90分）

- 高度なポスト処理を含める。
- 複数アプリケーションにまたがる連成解析は、**このレベルでのみ**、任意（必須ではない）で扱ってよい。
- **含む**: 高度な形状/解析、詳細なポスト処理（フィールドプロット、複数条件の比較等）、任意の連成解析。
- **含まない**: expert 相当の Python データ処理重視の内容（hard では AEDT 内の機能を中心に据える）。

## expert（目安90分以上）

- 複数アプリケーションの利用よりも、matplotlib 等を使った Python でのデータ処理・後解析を重視する。
- 連成解析は扱わない（hard で任意採用済みのため、expert では純粋なPython後処理にフォーカスする）。
- **含む**: AEDTから抽出したデータのPythonでのカスタム可視化・集計・比較分析。
- **含まない**: 新規の複数アプリ連成、AEDT操作そのものの複雑化。

## レベル間の判断に迷ったときの目安

| 観点 | easy | normal | hard | expert |
|---|---|---|---|---|
| アプリ固有知識 | 不要 | 必要 | 必要 | 必要 |
| Setup作成・解析実行 | なし | あり（基本） | あり（発展） | あり（前提） |
| 複数アプリ連成 | なし | なし | 任意 | なし |
| Pythonでの後処理 | なし | なし（AEDT内で完結） | 一部 | 中心 |
