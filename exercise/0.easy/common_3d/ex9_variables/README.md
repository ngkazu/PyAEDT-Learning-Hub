# 演習9: プロジェクト変数とデザイン変数を作る・変更する

**目安時間: 30分**

題材: 特定の公式サンプルはなし。`0.easy/common_3d/ex1_basic_operations/` で扱った「デザイン変数」を
掘り下げ、「プロジェクト変数」との違いを学ぶ準備運動。

## アプリケーションの選び方

この演習はアプリケーションに依存しない（3Dモデラー系であれば同じ手順で進められる）。
[docs/app-selection.md](../../../docs/app-selection.md) の `common_3d` 分類（HFSS / Maxwell 3D / Icepak /
Q3D Extractor / IcepakFEA）から好きなアプリケーションを1つ選び、`starter.py` 冒頭の import とアプリ生成部分を
書き換えてから進めること。以降の説明では例として `Icepak` を使う。

## 学習目標

- デザイン変数（そのデザインだけで使える変数）とプロジェクト変数（プロジェクト内の全デザインで共有できる
  変数）の違いを理解する
- `app["変数名"] = "値"` という同じ構文で、変数名の先頭に `$` を付けるかどうかだけで
  デザイン変数／プロジェクト変数を使い分けられることを知る
- 両方の変数を組み合わせた数式を、形状のパラメータに使う

## 課題

`starter.py` の `# TODO` を埋めて、次の仕様を満たすスクリプトを完成させてください。

1. [docs/app-selection.md](../../../docs/app-selection.md) から使いたいアプリケーションを選び、
   `starter.py` の import 文とアプリ生成部分を書き換える。
2. `new_desktop=True`, `non_graphical=False` でアプリケーションを起動する。
3. デザイン変数 `design_box_size = "10mm"` を定義する（`app["design_box_size"] = "10mm"`）。
4. プロジェクト変数 `$project_scale = "2"` を定義する（`app["$project_scale"] = "2"` のように、
   変数名の先頭に `$` を付ける）。
5. `sizes=["design_box_size*$project_scale", "design_box_size*$project_scale", "design_box_size"]` の
   ように、両方の変数を使った式で箱 `"MyBox"` を作成する。
6. デザイン変数 `design_box_size` の値を `"20mm"` に変更する。
7. プロジェクト変数 `$project_scale` の値を `"3"` に変更する。
8. プロジェクトを保存する。
9. `release_desktop()` でAEDTを終了する。

## ヒント

- デザイン変数とプロジェクト変数は、どちらも `app["変数名"] = "値"` という同じ構文で定義・変更できる。
  違いは変数名の先頭に `$` があるかどうかだけ（`app["$変数名"]` ならプロジェクト変数になる）。
- GUIで確認する場合、デザイン変数は「Properties」ウィンドウの「Local Variables」（またはデザイン名の下）、
  プロジェクト変数は「Project Variables」に表示される。
- プロジェクト変数は、同じプロジェクト内に複数のデザインがある場合、すべてのデザインから参照できる
  （例えば、複数のアンテナ設計で共通の周波数帯を1つのプロジェクト変数として管理する、といった使い方ができる）。

## 評価基準

- [ ] 選んだアプリケーションが起動し、デザイン変数 `design_box_size` とプロジェクト変数 `$project_scale`
      が定義されている（GUIでそれぞれ別の場所に表示されることを確認する）
- [ ] `MyBox` が両方の変数を使った式で作成されている
- [ ] `design_box_size` が `20mm`、`$project_scale` が `3` に更新され、形状サイズに反映されている
- [ ] プロジェクトが保存され、`release_desktop()` で正しく終了している

## 発展課題（任意）

- 同じプロジェクト内にもう1つデザインを追加し（`app.insert_design()` 等）、
  そのデザインから同じプロジェクト変数 `$project_scale` を参照できることを確認してください。
- GUIの「Properties」ウィンドウから、直接プロジェクト変数を編集してみて、
  スクリプト側から定義した変数と同じように扱えることを確認してください。
